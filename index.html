주요 기능

신호를 확인하고,
점검한 내용을 남기세요.

시운전과 배선 점검에는 IO 체크를, 설비 상태를 살펴볼 때는 모니터를 사용합니다.

01 · 모니터링과 IO 체크

필요한 신호를 모아,
값과 상태를 한눈에.

X/Y/M/L/B 비트와 D/W/ZR 워드를 자동 폴링합니다. 검색과 그룹, 상태 필터로 필요한 디바이스를 찾고, IO 체크에서 OK/NG 결과를 기록하세요.

  • 수동, 자동, 안내형 순차 IO 체크
  • 10진, 16진, 실수, 문자열 등 값 표시
  • 배선 맞바꿈과 단락 점검
  • 점검 결과와 통신 오류를 구분해 확인
  • CSV와 요약 리포트로 결과 공유

자동 점검은 설비를 자동 운전하거나 출력을 강제로 켜는 기능이 아닙니다.

프로젝트와 작업 정리

가져오기

기존 주소와 코멘트 활용

GX Works의 코멘트/래더 CSV와 GX Works2 .gxw에서 디바이스를 가져옵니다. 원본과 대조한 뒤 사용하고, 정확한 데이터가 필요하면 GX Works에서 내보낸 코멘트 CSV를 우선 사용하세요.

프로젝트

설비별 구성을 저장

디바이스와 그룹을 프로젝트별로 관리합니다. .plc 파일로 내보내거나 다른 Android 기기에 가져와 작업 구성을 이어갈 수 있습니다.

기록과 공유

점검 결과를 다시 확인

점검 결과와 로그를 확인하고, 필요한 결과를 CSV와 요약 리포트로 공유합니다. 일부 저장·가져오기 기능에는 광고 토큰 이용 조건이 있습니다.

스마트폰에서 PLC의 IP와 포트로 접근할 수 있어야 합니다. 연결 설정은 실제 PLC 파라미터에 맞춰주세요.

  1. 01

    PLC Ethernet 설정 확인

    MC Protocol/SLMP 포트, TCP/UDP, 프레임과 데이터 형식을 확인합니다.

  2. 02

    프로젝트와 연결 설정

  3. 03

    디바이스 등록

    주소를 직접 등록하거나 GX Works 자료에서 디바이스와 코멘트를 가져옵니다. 가져온 결과는 원본과 대조하세요.

  4. 04

    값 확인과 점검 기록

    모니터에서 읽기 상태를 확인한 뒤 IO 체크를 시작합니다. 설비에 신호를 인가하는 작업은 현장 안전 절차에 따라 별도로 진행하세요.

사용 전 확인

설비 값을 바꾸지 않는
읽기 전용 도구입니다.

PLC의 값을 읽어 표시합니다. 쓰기 명령을 보내거나 출력을 강제로 켜지 않습니다.

연결과 가져오기는 별도로 확인

통신 지원 범위는 PLC CPU, 통신 모듈과 설정에 따라 다릅니다. GX Works 가져오기는 비공식 호환 편의 기능이며, 추출 결과에 누락이나 해석 차이가 있을 수 있습니다. 현장 적용 전에 반드시 원본과 대조하세요.

무료 이용과 기능별 조건

기본 IO 체크, 모니터링과 계산 도구는 무료입니다. 디바이스 등록 수에는 제한이 없지만, 무료 모니터링은 목록 상위 50개 활성 디바이스를 대상으로 합니다. 배너 광고가 있으며, 성공한 CSV 저장과 GX Works 가져오기 등에 선택형 광고로 얻는 토큰을 사용합니다.
