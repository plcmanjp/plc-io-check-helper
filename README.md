# PLC 엔지니어의 작은 업무수첩

**PLC 엔지니어의 작은 업무수첩**은 Mitsubishi MELSEC PLC의 입출력(I/O) 상태를 현장에서 점검하고 디바이스 값을 실시간으로 모니터링하는 Android 앱입니다.

PC나 전용 장비 없이 스마트폰에서 PLC에 Ethernet으로 직접 연결하고 MC Protocol/SLMP로 값을 읽습니다. 이 저장소는 공식 제품 안내, 다운로드 경로, 가이드 링크를 관리하며 앱 소스 코드는 포함하지 않습니다.

## 이용 범위와 광고

- 디바이스 등록 수에는 제한이 없으며 무료 모니터링은 목록 상위 50개 활성 디바이스를 대상으로 합니다.
- 기본 IO 체크, 디바이스 모니터링, 심플 로거의 진입/열람/기록, 계산기와 도구는 무료입니다.
- 앱 하단에 배너 광고가 표시됩니다.
- 선택형 보상형 광고를 완료하면 토큰 1개를 받습니다. 토큰은 성공한 LOG/IO CSV 저장, GX Works 신규 등록/코멘트 병합, 하단 배너 12시간 제거에 사용됩니다.
- 실패, 취소, 변경 0건에는 토큰이 차감되지 않습니다.
- 인앱결제와 현금성 보상은 없습니다.

## 주요 기능

- **IO 체크**: 등록한 X/Y 입출력을 현장에서 OK/NG로 점검합니다. 수동, 자동, 안내형 순차의 3개 모드를 지원하며 배선 맞바꿈과 단락을 자동으로 감지하고 결과를 CSV와 요약 리포트로 공유합니다.
- **이더넷 직접 통신**: MC Protocol/SLMP, TCP/UDP, 3E/4E Frame, Binary/ASCII를 지원합니다.
- **비트 디바이스 모니터링**: X/Y/M/L/B 등의 ON/OFF 상태를 확인합니다.
- **워드 디바이스 읽기**: D/W/ZR 등을 10진수, 16진수, 부호 있는 값, 32비트, 실수, 문자열 형식으로 표시합니다.
- **자동 등록과 그룹 관리**: 선두 주소, 증가 간격, 수량으로 디바이스를 일괄 생성하고 계층형 그룹, 접기/펼치기, 드래그 재정렬, 그룹 삭제, 검색과 상태 필터를 지원합니다.
- **배치 모니터와 IO 모아보기**: 주소를 직접 입력해 여러 값을 표로 조회하고 입력과 출력 신호를 구분한 카드로 확인합니다.
- **프로젝트 저장과 공유**: 여러 프로젝트를 저장하고 `.plc` 파일로 내보내 기기 간에 이동할 수 있습니다.
- **GX Works 가져오기**: GX Works2 프로젝트 `.gxw`, 코멘트/래더 CSV, 검증된 범위의 GX Works3 FX5U 프로젝트 `.gx3`에서 디바이스 코멘트를 가져옵니다. 신규 등록과 코멘트 병합, X/Y 코멘트 복구, 디바이스 종류별 또는 POU별 그룹, POU 트리 미리보기, 더블코일 경고를 지원합니다. `.gx3`는 검증된 M 디바이스 코멘트 범위만 지원하며 미지원 디바이스 코멘트가 섞인 프로젝트는 일부만 등록하지 않고 중단합니다. R04CPU 프로젝트는 등록하지 않습니다.
- **심플 로거**: BIT/WORD 직접 주소 조건이나 주기 트리거로 이벤트를 기록하고 최근 로그를 CSV로 내보냅니다. 저장 대기 기록은 다음 실행 시 복구해 누락과 중복을 방지합니다.
- **심플 HMI**: DISPLAY 값 표시, MOTION 이동, VISIBILITY 비트 가시성 바인딩을 지원합니다.
- **통신 설정 가이드**: 연결 설정 화면에서 GX Works의 PLC Ethernet 파라미터 설정 절차를 확인할 수 있습니다.
- **다국어와 테마**: 한국어, 영어, 일본어, 중국어 간체, 중국어 번체, 베트남어와 다크/라이트 테마를 지원합니다.

## 내장 계산기와 도구

앱에는 다음 11개 현장 도구가 포함되어 있습니다.

- 프로그래머 계산기: 진법 변환과 비트 연산
- 전자기어비 계산기: MR-J 서보 CMX/CDV
- 원둘레 계산기
- 삼각함수 계산기: 직각삼각형 변과 각도, 좌표와 방향각/거리
- 아날로그 스케일 계산기: A/D, D/A 카운트와 공학량 선형 변환
- 통신 코드 계산기: 체크섬과 CRC-16 검산
- 시리얼 통신 시간 계산기
- UVW 스테이지 계산기: 정렬 보정값과 축 이송량, 역산, 스트로크 리미트 판정
- Modbus RTU 프레임 생성기
- ASCII 코드표
- ASCII 입력기: 문자와 코드, PLC D 레지스터 워드값 변환

일부 계산기는 [웹 엔지니어 도구](https://plcmanjp.github.io/engineer-tool/)에서도 사용할 수 있습니다.

## 안전과 면책

이 앱은 읽기 전용 모니터링 도구이며 설비 값을 변경하지 않습니다.

본 앱은 Mitsubishi Electric Corporation과 무관한 독립 서드파티 앱이며 제휴, 보증, 승인 관계가 없습니다. MELSEC, GX Works와 관련 명칭은 각 권리자의 상표이며 호환성 표시 목적으로만 사용합니다.

GX Works2 `.gxw`와 제한된 GX Works3 `.gx3` 가져오기는 사용자가 보유한 파일에서 디바이스와 코멘트를 추출하는 비공식 호환 편의 기능입니다. 추출 결과는 참고용이며 일부 데이터가 누락되거나 다르게 해석될 수 있으므로 현장 적용 전에 반드시 확인해야 합니다. 정확한 전체 데이터가 필요하면 GX Works에서 코멘트 CSV로 내보낸 뒤 가져오는 방법을 우선 권장합니다. 암호 또는 보호가 설정된 파일은 열거나 우회하지 않습니다.
